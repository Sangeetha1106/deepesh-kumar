# Deepesh Kumar — The Transformation Coach

Official website for **Deepesh Kumar**, The Transformation Coach & Capability Development Specialist.

## Overview
This repository contains the static web application showcasing Deepesh Kumar's training and coaching programs:
- **Corporate Training & Coaching**: Developing people, leadership, emotional intelligence, communication, and mindset.
- **Automobile Training**: Bringing automotive technology, transmission systems, hybrid/EV architectures, and consultative customer engagement together.
- **About Deepesh Kumar**: Certifications (Master Trainer & Facilitator, Emotional Intelligence Coach, Ikigai Life Coach, Automobile Technology Trainer), story, and philosophy.
- **Connect**: Direct client enquiry form and contact details.

## Structure

## Running Locally
You can run this project with any local HTTP server:

```bash
# Using Python
python -m http.server 3000

# Using Node.js
npx serve .
```

Then visit `http://localhost:3000` in your web browser.
